# Hi, I'm Zo

AI and Software Engineering student at Centennial College in Toronto, with a Business Management diploma and a background in operations and logistics. I build local-first AI tools, agents and automation.

## What I'm building

- **Friday:** a personal AI assistant that runs on my own PC. Local wake word and speech-to-text (Whisper), local voice (Kokoro TTS), a searchable notes memory and scheduled jobs.
- **The Office:** a multi-agent dev setup where several AI coding agents work in parallel on a shared task board.
- **Content pipeline:** an automated Yu-Gi-Oh! news and short-form content system with a quality gate and performance tracking.
